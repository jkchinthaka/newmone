# Figma Review Checklist — Phase 01A

**Document status:** Manual review aid — not a completed review  
**Phase:** 01A  
**Last updated:** 2026-08-04

Use with [PHASE_01A_DESIGN_APPROVAL.md](../approvals/PHASE_01A_DESIGN_APPROVAL.md). Check items during design review sessions.

## Business accuracy

- [ ] Journeys match proposed MVP scope without claiming unapproved forms
- [ ] No invented temperature limits, CCP labels, site names, or shift rules
- [ ] Open items tagged ASSUMPTION / DECISION REQUIRED / OWNER REQUIRED / EVIDENCE REQUIRED
- [ ] Loading-block journey clearly marked Later where applicable

## Role boundaries

- [ ] Persona allowed/prohibited activities respected in wireframes
- [ ] Auditor flows mutation-free
- [ ] Admin cannot silently edit submitted operational answers

## Separation of duty

- [ ] Self-check / illegal verify combinations blocked in journey + wireframe notes
- [ ] SoD failures show Access denied / blocked messaging

## Mobile usability

- [ ] Operator path mobile-first; sticky primary actions
- [ ] ≤5 operator nav destinations documented as proposed
- [ ] Normal checklist path aims to be faster than paper (reviewer judgment + future timing test)

## Sinhala readability

- [ ] Operator labels planned Sinhala-first
- [ ] Layout allows string growth
- [ ] No fake final regulatory Sinhala presented as approved

## Accessibility

- [ ] Status not colour-only
- [ ] 48px minimum / 48–56px recommended targets noted
- [ ] Visible labels; error summaries specified
- [ ] WCAG 2.2 AA targeted, not claimed certified

## Offline terminology

- [ ] No “submitted” wording before server ACK
- [ ] Journey 6 states present in lo-fi / offline page plan

## Critical failure visibility

- [ ] Failure and LOADING BLOCKED treatments unmissable (text+icon+pattern)
- [ ] Incomplete critical failure cannot submit (Journey 2)

## Minimal typing

- [ ] Pass/fail and selects preferred over free text in lo-fi
- [ ] Numeric keyboard called out for measurements

## Auditability

- [ ] Journey steps list audit events
- [ ] Auditor pack includes template version, chain, amendments, history

## No invented data

- [ ] Placeholders used for unknown Nelna values
- [ ] Examples clearly marked as examples

## MVP scope

- [ ] Screens classified MVP vs Later in inventory
- [ ] NC/CAPA/ERP/AI/native app not smuggled into MVP as required

## Stakeholder sign-off

- [ ] Reviewers named on approval form
- [ ] Approved / Approved with conditions / Rejected recorded
- [ ] Conditions listed if any
- [ ] Form **not** pre-checked Approved
