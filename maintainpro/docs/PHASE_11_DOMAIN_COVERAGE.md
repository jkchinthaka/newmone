# Phase 11 — Company-wide Domain Coverage

**Branch:** `maintainpro/phase-11-domain-coverage`

Configures the **same** Asset / WO / PM / compliance engines across company domains. No duplicate engines.

Domain profiles expose applicable fields, KPI keys, example PM template codes, compliance type keys, and required closure fields.

Example PM codes are **configurable placeholders**, not verified Nelna frequencies.

Special scopes:
- Farm = physical infrastructure only
- IT = physical hardware only
- Outlets = Site with AC/chiller/freezer/electrical/plumbing/CCTV/signage support notes
